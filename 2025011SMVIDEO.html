Social Media Templates.

In late 2025, MassLive.com requested a set of templates meant for Social Media use, specifically Instagram, that could be used by Producers within Canva to quickly and efficiently create static and animated cards in two sizes that addressed a variety of use cases. I worked with the site as clients to establish what their pain points were and how to best address them. I interated out a set of over 100 templates with the idea that we could edit those down to a smaller set after a month by determining frequency of use. To my surprise, all of them were useful to the client and their Social Media production increased exponentially.

In early 2026, all of the other sites within Advance Local media asked for their own versions as well. That includes Cleveland.com (Cleveland, Ohio), MLive.com (Michigan), PennLive.com (Pennsylvania), LehighValleyLive.com (Easton New Jersey/Pennsylvania), AL.com (Alabama), GulfLive.com (Gulf areas of Louisiana, Mississippi and Florida), OregonLive.com (Portland, Oregon), Syracuse.com (Syracuse, New York), SILive.com (Staten Island, New York), NJ.com (New Jersey.)
Below are examples of highlights from several of the site versions.

MassLive Social Media Template | Quote Only

Three branding colors End users select one of the three branded options for single quote cards.

MassLive Social Media Template | Gradient Bottom

Text and Image flex Selective groupings allow for quicker editing. In this case the text flexes up from the bottom of the layout pushing the gradient up into the image.

MassLive Social Media Template | Border

Border End user can flex the image with a border image below. The image makes the empty space feel intentional and accommodates unusual image shapes and poorer image quality.

MLive Social Media Template | In Memoriam

Obituary card The template allows the end user to very quickly create a tonally appropriate Obituary card with a simple image, the name and birth year.

MLive Social Media Template | End Notes

Three branded color options + 2 text options One text option is meant for short simple end notes referring to the dotcom. The second text option is for longer text notes, especially useful for highlight stories.

MLive Social Media Template | Text Only

Non-Photo Card This template works well when no images fit the story or the end user would like to introduce dotcom content with intro text and a link.

NJ.com Social Media Template | Deal of the Day

Branded content: A quick easy to use template to highlight branded content.

NJ.com Social Media Template | X/Twitter

X The client needed a way of showing a screen capture of a tweet or other social media post from another person or group. This template accomplishes this while maintaining branding and intentionality.

NJ.com Social Media Template | Story in Full 01

Multipage template: This easy to edit template helps end users quickly compose multipage layouts for longer form stories.

GulfLive Social Media Template | Story in Full 02

Multipage template: This easy to edit template helps end users quickly compose multipage layouts for longer form stories.

GulfLive Social Media Template | List Animated

Animated template: This List style template allows the end user to produce an animated List style layout quickly and easily.

GulfLive Social Media Template | SIF Cover 01 02

Cover alternate 02 This template is designed to swap with a multipage layout cover to include an image.

OregonLive Social Media Template | SIF Cover 01 03

Cover alternate 03 This template is designed to swap with a multipage layout cover to include an horizontal image.

OregonLive Social Media Template | SIF Cover 0204

Cover alternate 04 This template is designed to swap with a multipage layout cover to include an image.

OregonLive Social Media Template | Animated List

Animated template 9:16: This List style template allows the end user to produce an animated List style layout quickly and easily for 9:16 screens (examples would include Reels).

9:16 Mag version: This is the 9:16 size version of the Magazine template, designed to accommodate more horizontal images for a traditional Magazine style layout.

Syracuse.com Social Media Template | Backs

Backgrounds: Branded Background Images are included on all sets of templates to not only present subtle branding but also fill space to create intenionality.

Cleveland.com Social Media Template | Fillers

Fillers: Branded Filler Images are included with each set of templates and on all templates that employ the filler images to help Producers counter images with difficult dimensions by filling the negative space with an intentional image that isn't dominant.

Cleveland.com Social Media Template |

4:5 Library: This template is meant as a support piece, giving the end user multiple elements that are used in the templates in a single location. I advised the producers to keep it open on their device and use it to copy and paste elements if needed.

Cleveland.com Social Media Template | Top5

Animated Top 5 layout This template was designed to make creating a more complicated "Top 5" style presentation easy. The end user just needs to drop relevent images along with editing the text objects and then export.

Programs used: Canva (which can be challenging in an Art Director role creating templates that are easy for end users.) Adobe Illustrator (for development of vector logos which insure better reproduction in Canva) Adobe InDesign (I used this to create a User Guide with clickable links to the templates and previews of what they look like and how to use them).
